# P10 — FR-05 kausal bersitasi (27 Sep 2026)

Tujuan: pertanyaan "kenapa"/"hubungan"/"kaitan"/"memengaruhi" dijawab dengan
bukti terdekat + batas kesimpulan tertulis, tanpa mengarang sebab-akibat,
dengan 0 klaim tanpa rujukan (FR-19).

## Perubahan kode

1. `src/lib/intent-meta.ts` — niat `sebab` diperluas:
   - Sebelum: `kenapa|mengapa|penyebab|disebabkan|faktor (penyebab|utama)|sebab`
   - Sesudah: `...|hubungan|kaitan|korelasi|memengaruhi|mempengaruhi|pengaruh|dampak|berhubungan|berkaitan`
   - Alasan: K1–K4 ("hubungan antara", "kaitan antara", "berhubungan", "memengaruhi")
     sebelumnya tidak terdeteksi sebagai sebab → evidence 14 acak, bukan 3 relevan.
   - `PANDUAN_NIAT.sebab` diperbarui: menyebut hubungan/korelasi ≠ kausalitas,
     sitasi per klaim, dan batas OPD/akademik.

2. `src/services/deterministic-answer.ts` — P10:
   - `KAUSAL_STOPWORDS` — daftar kata generik kausal yang TIDAK boleh jadi jangkar
     domain (penyebab, hubungan, kaitan, tinggi, tingginya, ...). Tanpa ini,
     "Perguruan Tinggi" tertangkap karena mengandung "tinggi" (terukur 27 Sep:
     N4 "penyebab tingginya stunting" → evidence ke-3 = "Jumlah Pik R Jalur
     Pendidikan Perguruan Tinggi").
   - `labelMengandungDomain()` — filter ketat: label harus mengandung token domain
     (bukan kata kausal generik). `tokenIsi(query)` → buang stopwords kausal →
     domainTokens.
   - `buildNarasiSebab()` — narasi khusus sebab:
     * Setiap evidence → satu kalimat `"indikator" tercatat <nilai>...`
       sehingga `beriSitasi()` dapat merujuk [n].
     * Struktur: angka terdekat sebagai konteks topik: <daftar>; penutup
       menegaskan batas: "Angka-angka di atas adalah konteks topik, bukan bukti
       sebab. SAPA tidak menyimpan variabel sebab-akibat, sehingga hubungan
       sebab-akibat tidak dapat disimpulkan..."
     * Pembuka/batas awal disediakan oleh `peringatanSebab` (wajib, dijaga
       `catatanWajib` pada jalur AI).
   - Evidence untuk sebab: filter domain ketat → fallback jangkar isi lama →
     slice 0,3. Sebelum P10: hanya `punyaJangkarIsi()` → longgar.

3. `src/services/bentuk-jawaban.ts` — sebab:
   - `catatan`: "SAPA menyimpan angka capaian, bukan analisis sebab-akibat.
     Angka di bawah adalah konteks terdekat, bukan bukti sebab — hubungan
     sebab-akibat tidak dapat disimpulkan dari katalog ini dan memerlukan
     kajian OPD/akademik. Setiap klaim angka dirujuk ke baris bukti [n] (FR-19)."

4. `src/lib/__tests__/kausal.test.ts` — 14 uji baru (P10):
   - 7 intent: hubungan/kaitan/berhubungan/memengaruhi/mempengaruhi/dampak/korelasi → sebab
   - 5 kausal umum: ≤3 bukti relevan, batas tertulis, 0 klaim tanpa rujukan
   - N4: tidak mengandung kata terlarang, semua evidence stunting
   - K1: tidak ada "Pik R"/"Perguruan Tinggi" lagi

## Sitasi per klaim (FR-19)

Untuk semua K* di atas, `sitasi.totalKlaim=1, bersitasi=1, tanpaSitasi=[]` → 0 klaim tanpa rujukan.
Mekanisme: setiap kalimat konteks memuat `<nilai>` yang ada di evidence, sehingga
`beriSitasi()` menemukan rujukan.

## Catatan jujur

- K2/K3 masih memuat 3 jalan saja, tanpa UMKM/kemiskinan eksplisit, karena domainTokens
  untuk query itu = [umkm, panjang, jalan, kecamatan] → filter substring "jalan"
  mendominasi. Idealnya: setidaknya satu bukti per topik (UMKM + jalan). Ini belum
  diimplementasikan karena butuh ranking per token, bukan sekadar filter. Namun
  hasil sudah jauh lebih baik daripada 14 acak, dan eval lulus (relevan = ada
  "jalan kabupaten").
- K4: "keluarga" cocok dengan "Keluarga Berencana Desa" (Sub Ppkbd) — bukan jumlah
  keluarga per desa, tetapi ini memang keterbatasan katalog (data keluarga per desa
  tidak ada). Jawaban jujur dengan konteks terdekat adalah perilaku yang benar.
